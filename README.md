# Specialisterne — Wireframe

Wireframe HTML del sitio de Specialisterne (proyecto Zoopa), con los 117 comentarios del cliente aplicados.

## Última versión — 2026-11-09

- **`index.html`** es la versión actual y **autocontenida**: las imágenes y el vídeo corporativo van incrustados dentro del propio HTML (base64), así que se ve con todo el contenido **sin necesidad de descargar nada**. Pesa unos 15 MB. Solo el globo 3D y la tipografía (Montserrat) se cargan de internet.
- Para verlo: abre `index.html` en cualquier navegador. El globo está en **About → Global presence**.

> Incluye: páginas de cursos (Career / University) reconstruidas, página **OUR SERVICES** con pestañas (Strategy / Execution / Result / Scalability), secciones Client cases (Problem → Solution → Results), y el resto de cambios acordados.

### Novedades respecto a la versión de junio

- **Globo 3D «Global presence»** (página About): arranca ya con tamaño reducido y se puede arrastrar para girarlo.
- **Mapa de presencia**: 27 países en amarillo y el resto en azul marino con fronteras blancas, tal cual el mapa de referencia del cliente.
- **11 pins de oficinas** (España, Portugal, Dinamarca, Islandia, Irlanda, Irlanda del Norte, Italia, Canadá, Estados Unidos, LATAM y Brasil) con el icono del diente de león y las posiciones del mapa de referencia.

La versión del 26 de junio de 2026 sigue disponible en el historial de commits.
